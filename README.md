## Проєкт

CampusReserve — навчальний проєкт вебсервісу для господарської та навчальної частин академії. Він має об’єднати бронювання аудиторій і обладнання, показувати зайнятість ресурсів, запобігати подвійним бронюванням і підтримувати погодження заявок на великі аудиторії. Контекст теми 5 описує окремі паперові журнали та невдалу спробу вести спільну таблицю. Початкове рішення для першого релізу: перевірити повний шлях заявки в одному корпусі, з погодженням відповідальним працівником, а масштабування планувати за результатами пілота. Назва продукту й межа пілота є нашими проєктними припущеннями; приймання замовником ще не проводилось.

Сума зайнятості: **5 FTE**. Стеля годин: **5 × 16 × 40 = 3 200 год**. У горизонті релізу вміщується **16 / 2 = 8 спринтів**, початковий орієнтир — **8 × 30 = 240 SP**. Це розрахунок за варіантом, а не виміряна продуктивність і не обіцянка поставити такий обсяг. Детальний план, резерви та оцінки з’являться в наступних роботах.

```powershell
python tools/validate.py lr01_case

python tools/validate.py lr05_charter
python tools/validate.py lr06_backlog
```
